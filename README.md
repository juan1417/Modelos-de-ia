# Modelos de IA — Universidad

Colección de notebooks de Google Colab con implementaciones de algoritmos de Machine Learning y análisis de datos desarrollados durante la carrera de Ingeniería de Software.

## Estructura

```
├── 01-fundamentos-pandas/     # Extracción de datos y manipulación con Pandas
├── 02-regresion-lineal/       # Regresión lineal y imputación de datos
├── 03-regresion-logistica/    # Regresión logística para clasificación
├── 04-arboles-decision/       # Árboles de decisión
├── 05-naive-bayes/            # Naive Bayes
├── 06-svm/                    # Support Vector Machines
├── 07-nlp/                    # Procesamiento de lenguaje natural
└── 8-otros/                   # Análisis de datos y otros temas
```
